Built an adjustable UR5 camera rig for validating perception and manipulation algorithms, since adopted lab-wide. Evaluated the effects of image cropping on YOLOv7 object detection using a large-scale dataset, and contributed to the lab's ongoing work on probabilistic human motion prediction for safe human-robot collaboration.
